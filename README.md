# Feed Me

Find food you actually want to eat near you.

## Quick Start

```
npm run dev
```

Then visit http://localhost:5173/

## Development Tools
       
| Tool | Description |
|---|---|
| Devbox | Package manager, nix-based. Used to install project dependencies  |
| Aider | CLI interface for LLMs |
| Vite  | Frontend build tool  |
